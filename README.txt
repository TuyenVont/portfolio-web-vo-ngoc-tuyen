PORTFOLIO WEB — VÕ NGỌC TUYỀN
================================

1) CÁCH CHẠY
------------
- Giải nén thư mục.
- Mở file index.html bằng Chrome/Edge.
- Hoặc dùng VS Code + Live Server.

2) CÁCH THAY ẢNH
----------------

Không cần sửa HTML.

3) FILE CHÍNH
-------------
index.html  : nội dung trang
style.css   : màu sắc, bố cục, responsive, animation
script.js   : menu mobile, hiệu ứng scroll, placeholder ảnh

4) MÀU SẮC
----------
Sửa nhanh trong style.css ở phần :root

--cream      nền kem
--blue       xanh pastel
--blue-2     xanh nhạt
--yellow     vàng nhạt
--brown      nâu chính
--blue-dark  xanh chữ nhấn
